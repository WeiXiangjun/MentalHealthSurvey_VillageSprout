# 第二部分：数据预处理

本部分保存问卷样本筛查、量化变量编码、缺失值规则和访谈材料整理过程。

- 三类问卷分别记录整份排除、题项级缺失、结构性缺失和变量转换。
- 开放题和访谈的正式主题编码不在本阶段进行。
- 访谈在本阶段仅处理提纲、校订稿、匿名化和文本来源说明；意义单元划分和编码进入第三部分。

## 本阶段成果

- `数据预处理记录.xlsx`：集中保存阶段边界、样本筛查、三类变量字典、质性材料准备清单、通用规则和来源变更记录。
- 学生、家长、教师和访谈四份数据预处理Word报告分别保存在对应子目录。

本阶段分别完成三类问卷的样本筛查、变量编码和缺失处理，并完成访谈材料的版本区分、匿名化与意义单元准备；详细规则记录于工作簿和四份预处理报告。
