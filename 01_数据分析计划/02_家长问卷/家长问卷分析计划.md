# 家长问卷分析计划

## 一、资料范围

家长问卷共回收91份，依据筛查规则排除4份具有明确重复证据的答卷，有效样本为87份。问卷包含有序题、条件题、参与和行动变量，以及两类文本材料。

## 二、研究问题

1. 家长对学校心理健康教育的了解度和满意度如何？
2. 家长是否参与学校活动，参与后的体验如何？
3. 家长对子女心理健康的重视程度是否高于自身心理健康知识水平？
4. 活动参与与了解度、满意度及校外行动是否相关？
5. 主动寻求学校外支持的家长是否具有不同的知识或重视水平？
6. 家长具体使用了哪些校外支持方式？
7. 家长希望学校补足哪些课程、服务、沟通和个体支持？

## 三、量化变量与分析

| 变量 | 性质 | 预定处理 |
|---|---|---|
| P_Q1_SCHOOL_UNDERSTAND | 1—5有序 | 分布、中位数、四分位距、补充均值/标准差、4—5分比例 |
| P_Q2_SATISFY | 1—5有序 | 同上 |
| P_Q3_PARTICIPATE | 三水平有序 | 保留原分布；派生0=从未、1=偶尔、2=经常 |
| P_Q4_ACTIVITY_FEEL | 条件有序题 | 仅对实际参与且逻辑一致者分析；明确有效分母 |
| P_Q5_MH_KNOWLEDGE | 1—5有序 | 分布及与重视、行动的关系 |
| P_Q6_CHILD_IMPORTANCE | 1—5有序 | 分布及与知识、行动的关系 |
| P_Q7_EXTERNAL_SUPPORT_BIN | 二元 | 0=否、1=是；报告频数和比例 |

预定检验：

1. 满意度与了解度：配对Wilcoxon检验及Spearman相关。
2. 重视程度与知识水平：配对Wilcoxon检验及Spearman相关。
3. 参与程度与了解度、满意度：Spearman相关；参与过与从未参与组使用Mann-Whitney U检验。
4. 是否寻求校外支持与知识、重视：Mann-Whitney U检验。
5. 是否参与学校活动与是否寻求校外支持：Fisher精确检验并报告优势比。
6. 同一组分组比较采用Holm校正。

## 四、文本质性分析

正式分析纳入两个文本字段：

1. `P_Q7_EXTERNAL_SUPPORT_TEXT`：选择“是”后填写的具体支持方式；
2. `P_Q8_SUGGEST_TEXT`：对学校心理健康教育建设的建议。

Q7文本用于识别家长实际连接的资源类型，如亲子沟通、阅读课程、医疗/咨询、社会活动或其他支持；Q8用于归纳对学校课程、活动、专业服务、家校沟通和特殊群体支持的期待。P052等质量标记文本保留原记录，但不进入主题频次时需说明理由。

## 五、来源内整合

比较“高重视”与“知识/行动是否跟上”，以及“参与学校活动”与“具体使用何种校外资源”。无实质建议不能单向解释为完全满意，也可能反映不了解可提出什么要求。

## 六、解释边界

家长参与与积极评价之间存在自我选择的可能。横断面数据不能证明学校活动提升了满意度或导致校外求助。样本不能代表所有家长。
