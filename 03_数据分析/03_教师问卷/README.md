# 教师问卷正式分析

- `教师问卷正式分析.xlsx`：保存17名教师的关键结果、类别分布、多选题、“不清楚”比例及补充文本编码。
- 教师样本较小，以描述统计和材料内部解释为主。
- 教师补充文本由编码员1和编码员2平行独立编码。编码员1原表按17名教师横向保存，规范化后形成28个非空“教师ID×题号”单位；编码员2覆盖相同28个单位，两套材料可逐条对齐。
- 两套代码抽象层级不同：编码员1使用简洁的题内主题代码，编码员2进一步形成初始代码、二级范畴和主题。因此本项目保留两套编码，在主题层面比较，不把标签字面差异直接计算为Cohen's κ。
- `01_量化分析`保存统计代码和正式图件；`02_开放题质性分析`保存双编码证据链、代码本、比较记录及按题生成的编码词云/主题图。
