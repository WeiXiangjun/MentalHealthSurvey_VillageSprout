# 学生问卷量化分析

本目录保存学生问卷量化分析的可复现代码、统计结果索引和正式图件。`代码/run_quantitative_analysis.py`用于在取得原始逐份作答矩阵后复现统计分析；`代码/generate_figures.py`直接读取上级目录的`学生问卷正式分析.xlsx`生成图件。

当前正式数值以`学生问卷正式分析.xlsx`为准。原始逐份作答矩阵尚待归档，因此不得将现有汇总表反向还原为个体数据。

## 图件说明

- `图1_了解与满意分布`采用1—5级评分的横向堆叠比例图，冷色表示较低评分，暖色表示较高评分。
- `图2_年级编码组比较`展示各匿名年级编码组的平均分，误差线表示标准差。年级代码尚无可靠文字标签，因此只保留“编码组1—3”。
- 图内只保留标题、必要坐标名称和图例；样本范围、评分含义及误差线说明在本说明和报告图注中交代。
