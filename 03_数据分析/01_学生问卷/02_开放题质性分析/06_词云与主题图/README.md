# 词云与主题图

`代码/generate_qualitative_figures.py`读取`学生问卷正式分析.xlsx`中的`质性_编码员1逐条`，直接以编码员1保存的完整代码标签作为词云基本单元，不对原始回答自动分词。

词云按题目分别生成：Q3课程主题、Q4活动形式、Q5改进期望各有独立的编码频次CSV和词云PNG，不将三道题混合。代码标签可以多重出现，使用中文分号、顿号或逗号拆分多重编码，但保留代码名称中的斜杠。字体大小与颜色醒目程度均随频次增加，采用灰—红渐变且不设置色条。

展示性图件和配套频次CSV排除`无实质回答`、`无明确期望`、`其他/含义不明`和`排除文本`等非实质性代码，只呈现具有明确内容含义的主题。上述代码仍原样保留在逐条编码表和代码本中，过滤仅作用于可视化，不改变原始编码结果。主题分布图同样按Q3、Q4、Q5分成三个面板。
