# 第三部分：正式数据分析

本目录按学生问卷、家长问卷、教师问卷和访谈四类资料分别保存正式分析证据链。每类资料均包含一份正式分析工作簿；量化代码、质性可视化代码和输出图件均放在相应分析单元内部。

三类问卷分别完成描述统计与预定的推断统计，开放文本和访谈材料分别完成内容分析或主题分析。配套代码用于批量处理、结果输出和质量检查。

两位编码员采用平行独立编码，彼此不存在主次关系。若两套代码的分析单位或抽象层级并不完全同构，则保留两条编码路径并进行主题层面的交叉核对，不计算缺乏同层级标签基础的形式化一致性系数。教师题内补充文本的两套编码材料均已归档，并覆盖相同的28个“教师ID×题号”分析单位；由于代码抽象层级不同，采用单位覆盖核对、代码本对照和共同主题整合。
