# 词云与主题图

本目录保存家长Q8建议的编码频次、词云和主题分布图。所有图均以`质性_编码员1逐条`中的`建议编码`为来源，不对建议原文自动分词。

家长问卷只有Q8进入本次开放题双编码分析，因此生成一张Q8独立词云，不与其他题目或其他来源混合。多重代码按中文分号、顿号或逗号拆分，完整代码标签作为绘图单位。字体大小和颜色醒目程度随频次增加，采用灰—红渐变且不添加色条。

展示性图件和配套频次CSV排除`无实质建议`、`其他/含义不明`和`排除文本`等非实质性代码，只呈现具有明确建议含义的主题。上述代码仍原样保留在逐条编码表和代码本中，过滤仅作用于可视化，不改变原始编码结果；`认可现状`具有明确评价含义，因此继续保留。
